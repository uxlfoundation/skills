# UXL Skills project status — 2026-09-04

The project is ready for maintainer review, but the skills are not yet project-owned or proven to improve agent performance.

## Ready to share

- Eight skills are public: six oneAPI library skills plus shared SYCL build/debug and performance-validation skills.
- The Harbor catalog declares 52 tasks: 41 implemented and 11 deliberately visible as planned gaps.
- The public UXL Skills Evaluator shows portfolio, skill, task, methodology, and target-lane views.
- Ten UXL-branded maintainer decks are available as PowerPoint and PDF: one overview, one specialized-target guide, six library briefings, and two shared-skill briefings.
- Each skill has a maintainer review packet and current official-source ledger.
- One sanitized specialized-target qualification is public; raw machine evidence remains access-controlled.

## What the evidence currently means

- Implemented tasks prove that the task and verifier run; smoke or ceiling tasks do not prove skill benefit.
- No accepted matched evaluation record currently establishes improvement across model, harness, and environment cells.
- Hardware qualification proves a runner lane can execute its oracle; it is separate from evaluating a skill.
- The dashboard reports skill and evaluation health, not the health or performance of the underlying library.

## Remaining external gates

1. Each project reviews its skill and names an owner or periodic reviewer.
2. Maintainers correct scope and nominate authentic, recurring incidents where current agents have room to improve.
3. Selected tasks receive repeated, matched no-skill, previous-skill, and candidate-skill trials in declared evaluation cells.
4. Skills are promoted only after the review, source, evidence, and policy gates pass.

The immediate next step is outreach: ask every project for one substantive correction and one ownership decision.
