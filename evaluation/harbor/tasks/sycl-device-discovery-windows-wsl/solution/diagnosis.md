Build success does not establish runtime GPU availability. The attached `sycl-ls` and kernel probe must show the expected Intel GPU, select it through the Level Zero runtime, execute work, and verify the result before application-level debugging proceeds.

On Windows/WSL, verify `/dev/dxg` rather than `/dev/dri`. The Windows GPU driver must expose that interface to WSL. The container must receive `/dev/dxg`, mount `/usr/lib/wsl` read-only at the same path, and prepend `/usr/lib/wsl/lib` to the image's existing `LD_LIBRARY_PATH`; replacing the image path can hide oneAPI libraries. Record `ONEAPI_DEVICE_SELECTOR` and the legacy `SYCL_DEVICE_FILTER` because either can hide an otherwise usable device. Compare `sycl-ls` with the host evidence, then repeat the minimal SYCL smoke test against the selected GPU. Preserve the probe, compiler version, device listing, kernel output, and runtime error as evidence for the next escalation step.
